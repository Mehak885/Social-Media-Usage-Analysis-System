# Social-Media-Usage-Analysis-System
Python mini project for analyzing social media usage pattern
Social Media Usage Analysis System

1. Abstract

The Social Media Usage Analysis System is a Python-based mini project that analyzes daily social media usage patterns. It compares the time spent on different platforms and identifies the most-used platform.

2. Objectives

* Analyze daily social media usage.
* Compare different social media platforms.
* Calculate total and average usage time.
* Identify the most-used platform.
* Display results using charts.

3. Technologies Used

* Python
* Pandas
* Matplotlib

4. Project Implementation

The system stores sample usage data for Instagram, YouTube, Facebook, Snapchat, and WhatsApp. Pandas processes the data, calculates statistics, and identifies the platform with the highest usage. Matplotlib displays a bar chart of daily usage.

5. How to Run

1. Install Python.
2. Install the required libraries:
    pip install pandas matplotlib
3. Run the program:
    python social_media_analysis.py

6. Expected Output

* Social media usage table
* Total daily usage: 10 hours
* Average usage per platform: 2 hours
* Most-used platform: Instagram
* Bar chart showing daily usage

7. Conclusion

This project demonstrates how Python can be used for basic data analysis and visualization. It helps users understand social media usage patterns and encourages better time
